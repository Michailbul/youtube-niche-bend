# niche-bend (Claude Code plugin)

```
/plugin install niche-bend --marketplace Michailbul/youtube-niche-bend
```

Install and usage: the repo's top-level `README.md`. How it runs on a new machine (owners, the `niche-bend/` data
folder, Gallery or local boards, what to install): `skills/niche-bend/references/setup.md`.

- `skills/niche-bend/`: the method (entry point)
- `skills/niche-bending-youtube-analyzer/`: research scripts and references
- `skills/video-idea-proposals/`: proposals, title tests, ideas and thumbnail boards
- `skills/niche-bend-harness/`: optional loop runner, 3D board, MCP server, tests
- `agents/`: six research subagents
- `commands/`: `/niche-bend:setup`, `round`, `bend`, `occupied`, `idea`, `titles`, `more`, `board`, `keep`
